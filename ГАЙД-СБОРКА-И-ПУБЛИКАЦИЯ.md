# ГАЙД: сборка установщика CONVERT, установка и публикация на GitHub

Это пошаговая инструкция для Windows 10/11. Никаких знаний Rust не требуется — все команды копируются целиком.

---

## ЧАСТЬ 1. Что у вас должно быть (один раз)

| Инструмент | Ссылка | Зачем |
|---|---|---|
| **Git** | https://git-scm.com/download/win | публикация кода на GitHub |
| **Node.js 20+** (LTS) | https://nodejs.org | сборка frontend |
| **Rust (rustup)** | https://rustup.rs → скачать `rustup-init.exe` → запустить → Enter | компилятор Rust |
| **Visual Studio Build Tools** | https://visualstudio.microsoft.com/visual-cpp-build-tools/ → отметить «Desktop development with C++» | линковщик MSVC для Rust |
| **WebView2** | Уже есть в Windows 10/11 (установщик скачает сам при необходимости) | движок интерфейса |

После установки **перезагрузите компьютер** (чтобы PATH обновился), затем проверьте в `cmd`:

```bat
git --version
node --version
rustc --version
```
Все три должны показать версии.

### Опциональные компоненты (для видео/документов/OCR)

Приложение работает и без них — соответствующие студии честно сообщат, что компонент не найден.

| Компонент | Ссылка | Что даёт |
|---|---|---|
| FFmpeg | https://www.gyan.dev/ffmpeg/builds/ → «release-full» → распаковать, папку `bin` добавить в PATH | Video/Audio Studio |
| LibreOffice | https://www.libreoffice.org/download | Document Studio |
| Tesseract OCR | https://github.com/UB-Mannheim/tesseract/wiki (UB-Mannheim build) | OCR Studio |
| Русский язык Tesseract | при установке отметить «Russian» или скачать `rus.traineddata` в `C:\Program Files\Tesseract-OCR\tessdata` | OCR на русском |
| poppler | https://github.com/oschwartz10612/poppler-windows/releases → распаковать, `bin` в PATH | OCR сканов PDF |

## ЧАСТЬ 2. Первый запуск в режиме разработки (проверка, что всё работает)

```bat
git clone <ваша-ссылка> convert
cd convert
npm --prefix app install
npx tauri dev
```

- Первый запуск скачает ~300 крейтов и соберёт их (5–15 минут).
- Откроется окно CONVERT — можно пользоваться.
- Закрыть: Ctrl+C в консоли.

Если ошибка `link.exe not found` — не установлены VS Build Tools (см. Часть 1).

## ЧАСТЬ 3. Сборка установщика на вашей машине

```bat
cd convert
npm --prefix app install
npx tauri build
```

Результат (после 10–20 минут сборки):

```
src-tauri\target\release\bundle\nsis\CONVERT_0.1.0_x64-setup.exe   ← основной установщик
src-tauri\target\release\bundle\msi\CONVERT_0.1.0_x64_en-US.msi    ← вариант MSI
```

**Что делает установщик (NSIS):**
- ставит в `%LOCALAPPDATA%\Programs\CONVERT` (права администратора не нужны);
- создаёт ярлыки в меню Пуск и на рабочем столе;
- добавит в контекстное меню проводника «Открыть в CONVERT» (для любых файлов и папок);
- зарегистрирует CONVERT в списке «Открыть с помощью» для png/jpg/pdf/mp4/... — **не перехватывая ассоциации по умолчанию**;
- при удалении (Параметры → Приложения → CONVERT) полностью чистит записи реестра.

## ЧАСТЬ 4. Установка

1. Запустите `CONVERT_0.1.0_x64-setup.exe`.
2. Выберите язык (русский/английский) → Далее → Установить.
3. Готово. Проверьте: правый клик на любом файле в проводнике → «Открыть в CONVERT».

**Куда пишутся данные приложения:** `%APPDATA%\CONVERT\convert.db` (история, настройки, сценарии). Удаление приложения эти данные не трогает — стереть можно вручную.

**Обновление:** запустите новый установщик поверх старого — он обновит приложение, сохранив историю и настройки.

## ЧАСТЬ 5. Публикация проекта на GitHub

### 5.1 Создайте репозиторий

1. Зайдите на https://github.com → **New repository**.
2. Имя: `convert` (или любое), вид: **Private** (рекомендую для начала) или Public.
3. **Не** ставьте галочки README/.gitignore (они уже есть). → **Create repository**.

### 5.2 Загрузите код

В папке проекта:

```bat
cd convert
git init
git add .
git commit -m "CONVERT: полная версия (движки + UI + CI)"
git branch -M main
git remote add origin https://github.com/<ВАШ_ЛОГИН>/convert.git
git push -u origin main
```

При запросе логина GitHub используйте **Personal Access Token** (Settings → Developer settings → Personal access tokens → Tokens classic → Generate) вместо пароля.

### 5.3 Проверьте файл .gitignore

В репозитории уже есть правильный `.gitignore` (не пушатся `target/`, `node_modules/`, `.rustup/`, `.cargo/` — это сотни мегабайт мусора).

### 5.4 (Опционально) Сборка установщика через GitHub Actions — без Windows-машины!

В репозитории уже есть workflow `.github/workflows/build-windows.yml`. Он соберёт установщик в облаке GitHub:

1. Загрузите код (см. 5.2).
2. Создайте тег релиза:
   ```bat
   git tag v0.1.0
   git push origin v0.1.0
   ```
3. Подождите ~15 минут: вкладка **Actions** → «Build Windows Installer» → зелёная галочка.
4. Установщики лежат там же: **Actions** → последний запуск → внизу раздел **Artifacts** → `convert-windows-installers` (и появится черновик релиза на странице Releases с приложенными файлами).

Если Actions не запускается по тегу — откройте вкладку Actions, выберите workflow слева, нажмите **Run workflow** (он умеет ручной запуск).

### 5.5 Публичный релиз

1. GitHub → **Releases** → черновик «CONVERT v0.1.0» (создан workflow).
2. Проверьте описание, удалите пометку черновика → **Publish release**.
3. Ссылки на `.exe`/`.msi` теперь можно давать кому угодно.

## ЧАСТЬ 6. Частые проблемы

| Симптом | Решение |
|---|---|
| `error: linker link.exe not found` | Установить VS Build Tools с C++ (Часть 1), перезагрузка |
| `npm: command not found` | Node.js не установлен / терминал открыт до установки — перезапустить |
| Установщик требует интернет | Это WebView2 Bootstrapper (одноразово, ~2 МБ) — так и задумано |
| «FFmpeg не найден» в приложении | Установить FFmpeg и добавить `bin` в PATH, перезапустить CONVERT |
| OCR не видит русский | `rus.traineddata` в папку tessdata (Часть 1) |
| Actions собрался, но Artifacts пуст | Смотреть в самом релизе (draft) — там `if-no-files-found: warn` |
| Хочу пересобрать с новой версией | В `src-tauri/tauri.conf.json` и `src-tauri/Cargo.toml` поднять `version`, тег `git tag v0.2.0` → push |
